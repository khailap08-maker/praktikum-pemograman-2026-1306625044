## 1. Problem Statement
> Membuat program untuk mencari dan menampilkan faktor-faktor dari suatu bilangan

## 2. Mathematical Equation
> $$ N \bmod i = 0 $$
> $$ 1 \leq i \leq N $$

## 3. Algorithm
> 1. Mulai.
> 2. print judul "Mencari Faktor Bilangan
> 3. print Nama "Dyahayu Khaila Putri"
> 4. print NIM "1306625044"
> 5. input bilangan kurang dari 100.
> 6. Jika bilangan = 0, print "SELESAI", kemudian program berakhir.
> 7. Jika bilangan ≠ 0, buat list kosong untuk menyimpan faktor.
> 8. Inisialisasi i = 1.
> 9. Selama i <= bilangan, lakukan:
> 10. Periksa apakah bilangan % i == 0.
> 11. Jika benar, gunakan append(i) untuk memasukkan i ke dalam list faktor.
> 12. Jika salah, lanjutkan ke langkah berikutnya.
> 13. Tambahkan nilai i dengan i = i + 1.
> 14. Setelah perulangan selesai, gunakan print untuk menampilkan bilangan dan list faktor.
> 15. Kembali ke langkah 5 untuk memasukkan bilangan berikutnya.
> 16. Selesai.
